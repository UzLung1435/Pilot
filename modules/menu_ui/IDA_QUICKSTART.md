# 使用 IDA Pro 查找 A7C2 偏移量 - 快速指南

## 现状

✅ 你已经有了 `appFw.so.i64` - IDA Pro 数据库文件  
✅ 我已经创建了自动化工具来帮助你提取偏移量

## 快速开始（3步）

### 步骤 1: 在 IDA Pro 中打开数据库

```
1. 启动 IDA Pro
2. File -> Open 
3. 选择你的 appFw.so.i64 文件
4. 等待加载完成
```

### 步骤 2: 运行自动查找脚本

```
1. File -> Script file...
2. 选择: Pilot/modules/menu_ui/ida_find_offsets.py
3. 点击 OK
```

或者：
```
1. 按 Alt+F7 打开脚本命令窗口
2. 复制粘贴 ida_find_offsets.py 的内容
3. 按 Ctrl+Enter 运行
```

### 步骤 3: 查看和记录结果

在 Output 窗口（View -> Open subviews -> Output）查看结果：
- 段信息
- GOT 基址
- 找到的模式匹配
- 估算的偏移量

## 详细查找流程

### A. 自动化查找（推荐开始方式）

运行 `ida_find_offsets.py` 会自动：
1. ✅ 获取所有段信息
2. ✅ 定位 .got 和 .got.plt 段
3. ✅ 搜索关键模式（0x535, 0x1C3, 0x293等）
4. ✅ 查找 TextSprite::setString
5. ✅ 对比 a6700 偏移
6. ✅ 生成初步报告

### B. 手动验证（必需）

对于脚本找到的每个候选地址：

1. **跳转到地址**
   ```
   按 G 键
   输入地址（如：0x5B4BE70）
   ```

2. **查看数据结构**
   ```
   在地址上按 D 键：创建 QWORD
   按 U 键：取消定义（如果需要重新分析）
   ```

3. **查看交叉引用**
   ```
   在地址上按 X 键：查看 Xrefs to
   Ctrl+X：查看 Xrefs from
   ```

4. **分析周围内容**
   ```
   使用方向键浏览周围的数据
   检查是否有规律的结构
   ```

### C. 关键偏移的查找策略

#### 1. GOT_MENU_TABLE

```
策略：
1. 脚本已经找到 .got 段基址
2. 在 .got 段中查找指向菜单表的指针
3. 菜单表通常包含一系列结构体，每个约 0x18 字节

验证方法：
- 读取 GOT 条目指向的地址
- 检查是否是有效的数据区域
- 查看是否有规律的结构模式
```

#### 2. MENU_TABLE_OFF

```
策略：
1. 从 GOT_MENU_TABLE 读取指针值
2. 该值就是 MENU_TABLE_OFF
3. 或者搜索 0x535 找到自定义菜单组

验证方法：
- 检查结构是否包含 group_id
- 查看是否有多个连续的条目
- 对比 a6700 的结构
```

#### 3. PAGE_TABLE_OFF

```
策略：
1. 搜索 0x1C3, 0x293 等屏幕ID
2. 找到包含这些ID的表
3. 表中应该有函数指针

验证方法：
- 每个条目约 0x58 字节
- 包含 screen_id 和 factory 函数指针
- 指针应该指向代码段
```

#### 4. LAYOUT_1C3_OFF / LAYOUT_293_OFF

```
策略：
1. 从页面表找到对应的 view_factory 函数
2. 分析函数，找到它引用的布局数据
3. 或搜索包含坐标值的规律模式

验证方法：
- 布局表包含 UI 坐标（通常是合理的像素值）
- 每个条目约 0x60 字节
- 包含资源 ID（通常是 0x02XXXXXX 格式）
```

#### 5. 工厂函数偏移

```
策略：
1. 在 Functions 窗口搜索 "factory", "create"
2. 或从页面表中直接读取函数指针

验证方法：
- 函数开始于标准的 prologue
- 函数有合理的交叉引用
- 函数地址在代码段范围内
```

## 实用技巧

### 技巧 1: 使用 Hex-Rays 反编译器

如果有 Hex-Rays：
```
1. 跳转到函数
2. 按 F5 查看伪代码
3. 更容易理解函数逻辑
```

### 技巧 2: 创建结构体

```
1. 打开 Structures 窗口 (Shift+F9)
2. Insert 创建新结构
3. 定义字段（如 menu_row_entry）
4. 在数据上按 Alt+Q 应用结构体
```

示例：
```c
struct menu_row_entry {
    uint64_t group_id;
    uint64_t setting_desc;
    uint64_t non_setting_desc;
};
```

### 技巧 3: 使用书签

```
标记重要地址：
Alt+M: 添加书签
Ctrl+M: 查看书签列表
```

### 技巧 4: 比较 a6700

如果你也有 a6700 的 IDA 数据库：
```
1. 在两个 IDA 实例中打开
2. 对比相同功能的位置
3. 确认结构是否一致
```

### 技巧 5: 导出查找结果

在 IDA Python 中：
```python
# 导出到文件
with open("offsets_found.txt", "w") as f:
    f.write(f"GOT_BASE: 0x{got_base:x}\n")
    # ... 更多
```
