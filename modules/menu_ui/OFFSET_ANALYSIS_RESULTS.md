1. **0x535 匹配**: 在多个位置找到了 0x535 (PILOT_GROUP_ID)
   - 这些可能是菜单 ID 表中的条目

2. **数据结构模式**: 在估算的菜单表区域看到了规律的 qword 模式
   - 类似 `0x010001XX0000031f` 的重复模式
   - 这可能是菜单项描述符

3. **页面表结构**: 在估算的页面表区域看到了
   - 类似 `0x010000XX00000461` 的模式
   - 这可能是页面工厂条目
